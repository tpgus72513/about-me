# About Me — 자기소개 페이지

언더독 웹 기초 챌린지로 만드는 권세현의 자기소개 페이지입니다.
HTML과 CSS로 페이지를 구성하고, GitHub Pages로 배포하는 과정을 학습합니다.

## 프로젝트 목적

- HTML로 제목, 문단, 이미지, 링크 등 페이지의 구조를 작성합니다.
- CSS로 색상, 글자, 여백과 이미지 스타일을 적용합니다.
- Flexbox와 반응형 CSS로 다양한 화면 크기에 맞는 배치를 만듭니다.
- 단계별 작업을 Git 커밋으로 남기고, 배운 내용과 시행착오를 Velog에 기록합니다.
- 작성한 코드와 적용한 개념을 자신의 말로 설명할 수 있도록 학습합니다.

## 페이지에 담을 내용

- 이름과 간단한 자기소개
- 관심 분야와 학습 목표
- 대표 프로젝트와 담당 역할
- GitHub 및 Velog 링크

## 파일 구성 (예정)

```text
about-me/
├── index.html    # 자기소개 페이지의 내용과 구조
├── style.css     # 디자인, 화면 배치, 반응형 스타일
└── README.md     # 프로젝트 소개와 실행 방법
```

## 실행 방법

HTML 파일을 작성한 이후 아래 방법으로 확인할 수 있습니다.

1. 저장소를 컴퓨터에 내려받습니다.
2. `index.html`을 웹 브라우저로 엽니다.
3. HTML이나 CSS를 수정했다면 파일을 저장하고 브라우저를 새로고침합니다.

`index.html`과 `style.css`는 같은 폴더에 둡니다.

## 학습 순서

| 단계 | 작업 내용 |
| --- | --- |
| Day 1 — 준비하기 | Git·GitHub·Velog의 역할 이해, 개발 환경 확인, 저장소와 README 준비 |
| Day 2 — 뼈대 만들기 | HTML로 자기소개 페이지 구조 작성 |
| Day 3 — 꾸미기 | CSS로 색상·글자·여백·이미지 스타일 적용 |
| Day 4 — 배치하기 | Flexbox와 반응형 CSS로 화면 구성 |
| Day 5 — 완성하기 | 오류 점검, GitHub Pages 배포, 최종 회고 작성 |

Day 1~5는 학습 순서를 구분한 것이며, 실제 진행 날짜와는 다를 수 있습니다.
각 단계의 변경 사항은 커밋으로 남기고, 학습 과정은 Velog에 정리합니다.
